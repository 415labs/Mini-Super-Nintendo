# CAD files

Put the editable CAD sources for the Mini Super Nintendo / Super Famicom case in this folder (for example Fusion 360 `.f3d`, STEP `.step`, FreeCAD `.FCStd` or OpenSCAD `.scad`).

Printable meshes belong in [`../stl/`](../stl/).

Suggested contents:
- the case parts as editable sources
- a STEP export of the whole assembly so people can open it in any CAD program
- the mounting layout for the Raspberry Pi 4, the perfboard hub and the two SNES sockets (see [the build guide](../../docs/BUILD_GUIDE.md))
