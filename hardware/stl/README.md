# STL files

Put the print-ready `.stl` (or `.3mf`) files for the Mini Super Nintendo / Super Famicom case in this folder. The editable sources go in [`../cad/`](../cad/).

Add a short note here when you upload the files:
- printer, material and layer height you used
- which parts need supports
- screws and other hardware
- the licence for the models, for example CC BY-SA 4.0
